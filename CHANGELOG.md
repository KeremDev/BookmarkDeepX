# Changelog

## v1.0.0

Initial public release.

- Local-first X bookmark workspace.
- Passive X bookmark capture through the user's active browser session.
- Masonry bookmark board with search, filters, categories, titles, tags, folders, and tasks.
- X bookmark removal sync.
- Export/import for local BookmarkDeepX data.
- Turkish and English UI.
- GitHub Release ZIP packaging for Chrome/Chromium installation.
